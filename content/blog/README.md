# איך מוסיפים פוסט לבלוג

1. מעתיקים את `_template.md` לקובץ חדש בתיקייה הזו. שם הקובץ הוא הכתובת של הפוסט, באנגלית ועם מקפים, למשל `google-ads-tips.md` → `talmarketing.co.il/blog/google-ads-tips`.
2. ממלאים כותרת, תאריך, תקציר ותגיות, וכותבים את הטקסט. מוחקים את השורה `draft: true` כשהפוסט מוכן.
3. תמונות שמים בתיקייה `assets/blog/`.
4. מריצים `node scripts/build-blog.mjs` ושומרים (commit) גם את הקבצים שנוצרו בתיקייה `blog/` ואת `sitemap.xml`.

אפשר גם פשוט לשלוח לClaude את הטקסט של הפוסט, והוא יעשה את כל השלבים.
